# Agent Note: Second deduplication pass — error-alert idiom, viewer scaffolding, service mirror pairs

Status: implemented

## Problem

A second sweep (after
[the first pass](../2026-08-15-codebase-dedup-pass.md)) found the same
copy-paste families the first pass missed, in the exact spots where drift
becomes a bug:

- The catch-block idiom `window.alert(i18n.t(key, { ns: "errors", message:
  toIpcError(e).message }))` was hand-rolled at 16+ sites across Explorer,
  Settings (4 controls), PathControl, openFile, useExternalFileRouting,
  useAppCommands dispatch, and PackageDetail; the "pull `path` strings out of
  an error's `details` array" twin (`extractAffectedDocs` vs
  `extractOpenDocs`) lived in two components.
- `useAppCommands.handleCloseRequested` repeated the four-step exit tail
  (session → window state → clean-shutdown marker → destroy) in all three
  branches — a missed edit in one branch silently offers stale crash
  recovery.
- ImageViewer/PdfViewer each hand-rolled the `fs_changed` reload-key listener
  and the error/loading pane JSX; LinkModal, the assistant DiffModal, and
  FormulaModal still hand-rolled window-level Escape listeners that
  `useEscapeToClose` exists to own.
- `assistantStore` had three copies of the streaming-flush block (turn
  finalize / stop / message_end); `usePasteConvert` had two copies each of
  the paste re-validation gate and the image-template expansion.
- Backend: the `MiniWorld` test scaffolding was byte-identical ×3 in
  render/{svg,png,pdf}.rs (its own comment admitted a shared helper was
  due); `document_service` had two function pairs differing only by a
  3-line `hidden` guard; `save_coordinator` had five near-identical
  `Failed`-state blocks; `recovery.rs` duplicated the snapshot-write +
  manifest-upsert body between the sync and flush paths; `export_service`
  had private/public mirror render pairs; the paste-dest containment guard
  was copy-pasted between `fs_commands` and `net_commands`; the deprecated
  `assign_path` alias pair had zero callers.

## Decision

Extract one shared implementation per family; every behavior difference
stays at its call site as data or a one-line closure. No wire format, event
name, or command signature changed.

- `lib/ipc-error.ts` gains `alertIpcError(key, e, extra?)` (errors-namespace
  alert; cancellation deliberately NOT handled — callers keep their
  cancel-silent checks) and `extractDetailPaths(details, key)`. All 16+
  alert sites and both local extractors now funnel through them; i18n keys
  and error strings are unchanged.
- `useAppCommands`: private `shutdownWindow(excludeDocIds?)` owns the exit
  tail; the discard path passes the dirty set.
- `hooks/useFsReloadKey.ts` (path-matching `fs_changed` → reload key) and
  `Preview/ViewerStatus.tsx` (error/loading pane) are shared by both binary
  viewers.
- LinkModal, DiffModal, FormulaModal adopt `useEscapeToClose`
  (window-level + stopPropagation, identical semantics to what they
  hand-rolled). BatchExportDialog still keeps its own listener — the first
  pass rejected folding it (document-level, no stopPropagation).
- `assistantStore.flushStreaming(s)` pure helper absorbs the three flush
  blocks; `usePasteConvert` gains `livePasteTarget` (focus/model
  re-validation → live editor+selection or null) and `expandImageTarget`
  (template expansion + `ensureAbsolute`).
- `formatShortcuts` registers its seven commands from one data table;
  literals unchanged, pinned by a new
  `extensions/__tests__/formatShortcuts.commands.test.ts`.
- Dead frontend surface removed: the unused `clearConflict` wrapper in
  `tauri.ts` (the backend `clear_conflict` command remains registered but is
  now unreachable from the webview — the dialog's "Later" only closes
  locally) and the `IDLE_SAVE_STATE` export.
- Backend: `render/test_world.rs` (`#[cfg(test)]`) hosts the shared
  `MiniWorld`; `document_service`'s four queries become two `*_impl`
  helpers with `include_hidden: bool` (public names unchanged);
  `save_coordinator.fail()` records `Failed` and returns the same error;
  `recovery::write_snapshot_entry` owns the snapshot write + manifest
  upsert (error policy stays at the callers: propagate vs log-and-continue);
  `export_service`'s `render_pngs`/`render_svgs` bodies absorbed their
  private twins; `ipc::ensure_paste_dest` centralizes the paste-dest
  containment guard with byte-identical error strings; the dead deprecated
  `assign_path` pair is deleted.

New pinning tests: `alertIpcError`/`extractDetailPaths` (ipc-error.test.ts),
`useFsReloadKey.test.tsx`, `formatShortcuts.commands.test.ts`.

## Alternatives considered

- Folding the Explorer double-click handler into `lib/openFile.ts` (a live
  divergence hazard — Explorer re-implements the open-or-reactivate flow):
  deferred. Explorer's error text differs (`couldNotOpenFile` with the entry
  name + `console.error` context) and it owns a loading flag; merging
  changes user-visible wording and deserves its own focused PR.
- A generic `useBusyAction`/`useSettingAction` hook for the ~5 Settings
  busy-run blocks and dialog handlers: deferred. ActionControl's confirm
  prelude + console.warn variant and ConflictDialog's `isCancelled` checks
  make the shared shape parameter-heavy; only worth it once more call sites
  appear.
- Shared test `Emitter`/`wait_compiled` scaffolding across the 7 service
  test modules (~150 lines): deferred to its own PR — it touches seven test
  modules at once and the acquire/release semantics differ per suite.
- Unifying the `.typ` walkers (now four known: `fs_commands`,
  `project_config_service`, `bib_commands::discover_sync`, `fs::search`):
  still deferred — needs a decision on which exclude-glob behavior wins
  (they back different frontend surfaces).
- `ipc::ensure_paste_dest` pinning test: skipped — the guard is IPC glue
  over the (tested) `domain::path::ensure_contained_path`; constructing an
  `AppState` in a unit test costs more than the glue it would pin.

## Consequences

- ~340 net lines removed; PNG/SVG rendering, save-failure states, recovery
  snapshots, delete/search affected-doc scans, paste containment, and the
  three streaming-flush paths can no longer drift apart.
- The shared helpers are the canonical homes: extend `alertIpcError`,
  `useFsReloadKey`, `useEscapeToClose`, `write_snapshot_entry`,
  `ipc::ensure_paste_dest`, `render::test_world::MiniWorld` instead of
  writing local variants.
- `frontend-lib.md` / `frontend-state.md` / `frontend-components.md` /
  `backend-layers.md` / `backend-typst-engine.md` updated in the same PR.
- Verification: targeted vitest files per commit + the nine suites covering
  the touched modules (52 tests), `tsc -b` clean, `cargo test` full (649
  passed), `cargo clippy` clean except the one known frozen-`git/` warning.
