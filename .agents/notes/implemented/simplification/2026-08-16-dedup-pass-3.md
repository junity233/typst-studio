# Agent Note: Third deduplication pass — subscription factory, popup hooks, shared test scaffolding

Status: implemented

## Problem

A third sweep (after
[pass 1](2026-08-15-codebase-dedup-pass.md) and
[pass 2](2026-08-15-dedup-pass-2.md)) found the remaining copy-paste
families, including two items the earlier passes explicitly deferred to a
focused PR:

- `lspStore` + `tinymistInstallStore` carried byte-identical
  refcounted-subscription machinery (~130 lines): the memoized acquire
  (initial fetch raced against a 5 s timeout → `listen()`), the
  retry-clearing `.catch`, the refCount-0 release with microtask deferral,
  and the mount/unmount hook body.
- `ContextMenu` and `TableGridPicker` hand-rolled the same viewport-clamp
  math and 4-listener dismiss wiring (TableGridPicker's comments admitted
  "Mirrors ContextMenu.tsx"); `EditorArea`'s preview and diagnostics sash
  drags duplicated the pointer-event/`userSelect`/persist tail ("Mirrors
  the preview sash above").
- Six call sites imported `@tauri-apps/api/core` and invoked commands
  directly, violating the documented "tauri.ts is the ONLY place that
  calls `invoke`" invariant — two duplicated existing wrappers
  (`read_dir`, `create_entry`), and `lspStore`'s direct `get_lsp_status`
  call made `browserInvoke`'s case for it unreachable dead code.
- Six service test modules each carried a local `Emitter` double plus a
  polling wait (~490 lines total, 7 emitter impls) with drifted timeout
  counts and mixed panic-vs-silent timeout behavior.
- Backend: `save_core`/`save_as` duplicated the `spawn_blocking`
  write-result match tail; the exclude-glob synthetic-child check existed
  twice (`fs::search::path_excluded` ≡ `project_config_service::
  dir_excluded`) plus an `ignored_dirs()` HashSet twin in `bib_commands`;
  five pub fns had zero callers (`parse_open_recent`,
  `WorkspaceService::read_file_text`, `RecoveryService::cancel_pending`
  + its `Msg::Cancel` arm, `EditorWorld::set_vfs`, `EditorWorld::
  has_resolver`).

## Decision

Extract one shared implementation per family; behavior differences stay
at the call sites as data or closures. No wire format, event name, or
command signature changed.

- `store/refCountedSubscription.ts`: `createRefCountedSubscription({
  fetch, listen, apply, timeoutLabel, … })` owns the whole lifecycle and
  returns the subscriber hook. `lspStore`'s §6.4 generation gate stays in
  its `applyPayload` (passed as `apply`); `tinymistInstallStore` applies
  the raw payload. Pinned by the new
  `store/__tests__/refCountedSubscription.test.tsx` (single acquire for
  concurrent mounters, last-reader release, retryable failed acquire,
  timeout race, event funneling).
- `hooks/useClampedPopupPosition.ts` + `hooks/usePopupDismiss.ts`
  (callbacks in refs, listeners only while active — same shape as
  `useEscapeToClose`) shared by ContextMenu and TableGridPicker.
  `SubmenuPanel`'s clamp stays local: it anchors to a rect with a
  left/right flip, not to a point.
- `EditorArea`: module-level `startSashDrag(e, cursor, onMove, onEnd)`
  absorbs the shared drag tail; the per-sash axis math and persist keys
  stay at the call sites.
- `lib/tauri.ts` gains `getLspStatus` / `restartLsp` / `getWatcherHealth`;
  the six raw sites route through wrappers (`assistantStore`'s dynamic
  import now pulls `createEntry` from `lib/tauri`; StatusBar's local
  handler renamed `onRestartLsp`). Dead exports deleted: tabsStore
  `DEFAULT_CONTENT` / `useDocument` / `initTabs` (+ guards), the unused
  `GRID_SIZE` export.
- `service/test_support.rs` (`#[cfg(test)]`): `CapturingEmitter`
  (`CapturedEvent` + the per-suite accessors: `statuses`,
  `compiled_summaries`, `compiled_ids`, `compiled_full`, `conflicts`,
  …), `NoopEmitter`, and `wait_until(attempts, cond) -> bool`. All six
  suites converted; timeout POLICY stays at the call sites (panic vs
  silent return). `PanicOnCompiledEmitter` stays local (panics by
  design) but shares the extracted `make_tab`/`tabs_with` fixtures;
  `save_coordinator` and `watcher_health` use `NoopEmitter` (their
  recording doubles were never read).
- `save_coordinator.finish_write(id, revision, label, path, text, on_ok)`:
  the success transition stays at the call site (`mark_saved` vs
  `rebind_path_after_save`); join-error strings are byte-identical
  (`"save join error"` / `"save_as join error"` via the label).
- `fs::tree::ignored_dirs()` is the one HashSet builder (search +
  bib discovery); `fs::search::path_excluded` is `pub(crate)` and backs
  `project_config_service::dir_excluded`.
- The five dead pub fns (and `Msg::Cancel` + its worker arm) are deleted.

## Alternatives considered

- Full unification of the four `.typ` walkers: still deferred — depth
  caps, byte guards, and hidden-dir pruning intentionally differ per
  surface; only the byte-identical pairs were extracted. Drift flagged
  for a future pass: `walk_typ` matches `.typ` case-sensitively while
  `collect_typ_files` is case-insensitive, and `fs::search` does not
  prune hidden (non-`.git`) directories unlike the other three.
- A shared modal shell for the 8 dialog components (~100 lines):
  deferred — 4 portal vs 4 inline for no stated reason; unifying portal
  behavior changes stacking and needs visual verification.
- A generic `run_blocking` for the ~30 join-error maps: still rejected
  per pass 1 (bespoke contexts; labels are deliberately specific).
- De-exporting the seven internally-used-but-exported symbols
  (`MAX_HIDDEN`, `SUPPORTED_LANGUAGES`, `buildVscodeApiConfig`, …):
  skipped — churn without a drift hazard.

## Consequences

- Nine commits; ~1k insertions / ~1k deletions (the new shared homes +
  their pinning tests offset the deleted copies — the win is one
  canonical home per family, not raw line count).
- The subscription lifecycle, popup clamp/dismiss, sash drag, service
  test scaffolding, save write tail, and exclude-glob check can no longer
  drift apart; new status stores / popups / service suites should extend
  `refCountedSubscription`, the popup hooks, and `service::test_support`
  instead of writing local variants.
- Verification: targeted vitest files per commit + `tsc -b` clean;
  `cargo test` full — 649 passed (matches the pass-2 baseline), clippy
  clean except the one known frozen-`git/` warning.
- `frontend-state.md` / `frontend-shell.md` / `frontend-components.md` /
  `frontend-lib.md` / `backend-layers.md` / `backend-infra.md` updated in
  the same PR.
